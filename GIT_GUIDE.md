# Git guide (no command line needed)

We use **GitHub Desktop**: https://desktop.github.com

## First time
1. Sign in to GitHub Desktop with your GitHub account.
2. File > Clone repository > pick `simplex-sheet`.
3. The project is now a normal folder on your computer. Edit files there.

## Every work session
1. Click **Fetch origin**, then **Pull origin** if it appears. (Get the other person's changes.)
2. Edit your files. Test by opening `index.html`.
3. In GitHub Desktop, you see the changed files on the left.
4. Write a short message in the bottom-left box, click **Commit to main**.
5. Click **Push origin**. (Send your work to GitHub.)

## If you see a "conflict"
It means you both edited the same lines. Do not panic and do not delete anything.
GitHub Desktop shows the conflicting file. Open it, keep the right lines, remove the
`<<<<<<<` `=======` `>>>>>>>` markers, save, commit. Or message your partner and fix it together.

## Words
- **Commit**: save a snapshot on your computer.
- **Push**: upload your commits to GitHub.
- **Pull**: download the other person's commits.
- **Repository (repo)**: the project folder plus its history.
