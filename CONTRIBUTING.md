# Contributing

Two people, one rule set:

1. **Pull before you start.** Always get the latest version first.
2. **One small change per commit**, with a clear message ("Fix ratio check for dashes").
3. **Tell each other what you are editing**, especially if it is the same file.
4. **Test in the browser before you push.** Open `index.html` and try a preset.
5. **Do not push a broken page.** If it does not load, fix it or undo it first.

Bugs and ideas go in the GitHub **Issues** tab, one per issue.
